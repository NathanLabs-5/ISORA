# ISORA — Discover the beauty of Iceland

Uma experiência digital inspirada nas paisagens naturais da Islândia, desenvolvida para explorar conceitos de design minimalista, composição visual e desenvolvimento front-end.

## Sobre o projeto

ISORA é uma landing page conceitual que apresenta a Islândia como destino turístico por meio de uma interface visual imersiva.

A proposta é combinar elementos naturais, tipografia elegante e composição em camadas para transmitir a sensação de explorar um lugar extraordinário.

O projeto foi desenvolvido como prática de desenvolvimento front-end, com foco na construção de interfaces modernas e responsivas.

## Tecnologias utilizadas

- HTML5 — Estruturação da página.
- CSS3 — Estilização, layouts, responsividade e composição visual.
- JavaScript — Interatividade e manipulação de elementos da interface.

## Funcionalidades e características

- Interface minimalista e cinematográfica.
- Composição visual utilizando camadas de imagens.
- Tipografia personalizada.
- Layout responsivo.
- Navegação visual inspirada em experiências de turismo premium.

## Como executar

1. Clone o repositório:

```bash
git clone git@github.com:NathanLabs-5/ISORA.git
```

2. Entre na pasta do projeto:

```bash
cd ISORA/ISORA_Landing_Page
```

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão Live Server no Visual Studio Code.
