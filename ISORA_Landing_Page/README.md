# ISORA — Landing page

Projeto estático feito com HTML, CSS e JavaScript.

## Como executar
1. Extraia a pasta/arquivo ZIP.
2. Abra `index.html` no navegador.
3. Para desenvolvimento, você também pode abrir a pasta no VS Code e usar a extensão Live Server.

## Estrutura
- `index.html` — estrutura da página
- `style.css` — layout, tipografia, responsividade e efeitos
- `script.js` — menu mobile e indicadores de slide
- `assets/isora-iceland-hero.png` — imagem de fundo

A página usa Google Fonts (Playfair Display e DM Sans), então a tipografia depende de conexão com a internet. A imagem de fundo está incluída localmente.
